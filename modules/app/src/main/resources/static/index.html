Search is public. Everything that acts for a person — requesting a referral, answering one, verifying employment — needs an account.

Hybrid search

Runs BM25 and kNN together, fuses them by reciprocal rank, then applies an exponential freshness decay. Each result shows where it placed in each retriever, so you can see which leg found it.

Referral lifecycle

REQUESTED → ACCEPTED → SUBMITTED → CLOSED, with DECLINED and EXPIRED exits. Illegal moves are rejected by the domain layer, not by this page. Every action sends an Idempotency-Key, so pressing a button twice is a no-op, and the acting identity comes from your token rather than from anything this page sends.

Ingestion

Only public ATS board APIs: Greenhouse, Lever and Ashby. Registering a board queues it for an immediate crawl; the adaptive scheduler takes over from there. Registration is administrator-only, because a crawl spends somebody else's infrastructure budget.

LSH banding

The retrieval curve for the configured banding. Two postings become candidates when they agree on every row of at least one band; this is the probability of that happening at a given true Jaccard similarity.
